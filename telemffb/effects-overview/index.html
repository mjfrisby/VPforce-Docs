    1. Effects Overview¶

    This reference documents every effect and setting on the Settings tab. The pages mirror the tab itself: one page per section, entries in the same order the application lists them.

    1.1 The Settings-tab sections¶

    • Basic Settings - spring modes, force trim, axis control, and per-aircraft basics
    • Aerodynamics - airflow forces, stall buffeting, turbulence, ETL and VRS
    • Inertial - g-force, deceleration, and lateral-force effects
    • Ground - runway rumble, touchdown, nosewheel shimmy, ground steering feel
    • Mechanical\Airframe - engine rumble, moving surfaces and doors, damage, hydraulics
    • Weapons - gunfire, weapon release, countermeasures
    • Basic FFB Effects - damper, inertia, friction, deadzone (not telemetry-driven)
    • System - per-aircraft VPconf profiles, gain overrides, command runner, pause behavior

    1.3 How to read the entries¶

    Each effect entry opens with a badge line showing which simulators it applies to: DCS IL2 BMS MSFS XP - together with which device types can use it. Below the description, a table lists the effect’s sub-settings; its Sims column shows “—” when a sub-setting matches its parent, and names the sims only where it differs - that column is where the per-sim nuances live.

    Not every effect exists everywhere, and a shared name does not always mean identical behavior: some effects work from different telemetry per sim and expose different sub-settings (AoA/Stall Buffeting is the classic example). Where behavior differs, the entry says so in a Per-sim behavior note, and the simulator guides carry the depth.
