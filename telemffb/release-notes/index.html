    1. TelemFFB Release Notes¶

    New, improved, and changed functionality for each TelemFFB release, newest first. This is a curated summary of user-facing changes — for the complete commit history see GitHub.

    Tip

    Version names match the release tag on the wip branch. The most recent release is expanded below; click any older version to expand it.

    2.1.260815 — August 15, 2026 latest

    Platform

    • NEW: Aircraft profile notes
      • Many curated aircraft profiles now ship with notes explaining their quirks - why certain effects are disabled, control-system oddities, and custom-class aircraft where liveries must be cloned from the default profile rather than created new
      • You can also add your own notes to any profile
      • A notes button lives next to the Active Profile display and flashes green when the loaded aircraft has notes - click it to view/edit
    • Application Status panel: new ‘Telem Ovd’ indicator shows when the loaded aircraft has active SimConnect/Dataref telemetry overrides, with counts by tier (shipped default vs user-configured) and the full override list in the tooltip
    • Exception tracking and reporting system
      • New runtime exception tracker with UI viewer showing recent error history
      • Support bundle improvements: now includes DCS logs and Export.lua; switched to LZMA compression for smaller archives
    • In-app updater rewritten for reliability: per-phase progress (download/backup/extract), live status log, and auto-close-and-launch option
    • FFB Device Management enhancements
      • Auto-assign device paths for unconfigured slots on startup; selections are persisted in system settings
      • Improved USB device selector in System Settings — prevents duplicate device assignments across slots
    • Settings page usability improvements
      • The settings page no longer creeps/jumps its scroll position when you change a setting - the row you are working on now stays put under your mouse across the form refresh
    • The Settings tab now shows helpful guidance when it is empty (start a sim and load an aircraft, or open the offline editor) instead of a blank page - including a scope explainer when using the offline editor
    • Settings QoL: changing a setting back to its inherited/default value now automatically removes the user override (and the circle-x revert button) instead of leaving a redundant entry in your config
    • Application Status panel stability
      • The panel no longer resizes and shifts around when switching between device scopes
      • Any active ‘vpconf profile’ or ‘configurator gain override’ for a child instance device are now displayed when you change the config scope to that device
    • Curve editor usability improvements (Advanced Spring / Advanced G-Force widgets): smarter curve bounds checking, fixed point-insert resetting the first point, better endpoint drag behavior
    • TelemFFB now detects when a sim process exits and automatically resets telemetry listeners and UI state
    • Fix: configurator gain overrides not being applied when TelemFFB started with the sim already loaded into an aircraft
    • Fix: master instance was incorrectly validating child device PID when selecting per-aircraft vpconf profiles
    • Fix: IPC telemetry datagrams could be dropped under load in multi-device setups causing erroneous device icon failure status changes
    • Fix: cyclic spring gain not displaying in settings panel
    • Fix: error condition on app exit and SimConnect session halt
    • Fix: error handling when launching VPforce Configurator from the app
    • Fix: crash when telemetry startup is interrupted by a plugin update prompt

    XPlane

    • NEW: X-Trident AW109 special implementation - WIP Implementation
      • KNOWN ISSUE: Must map controls in-game and disable “Axis Control” in TelemFFB - Aircraft does not honor axis override dataref nor properly accept external axis control inputs
      • 4-Axis AFCS integration: cyclic trim rate control, force trim release, and autopilot following
      • Pedal/rudder trim integration
        • KNOWN ISSUE: Pedal AFCS is not as active as would be expected in real aircraft.. this is due to telemetry limitations from the aircraft
      • Collective spring gain and force trim release
    • NEW: 3-axis turbulence physics model with pitch/roll/yaw decomposition (shared with MSFS)
    • Updated plugin adhering to new stricter coding requirements
    • X-Plane plugin: Added dataref write and command write support for expanded aircraft control
    • X-Plane plugin: now exports vertical speed and pitch/roll rate data (used by the new trim calibration and future effects)

    MSFS / X-Plane

    • NEW: Automated Elevator Trim-Following Calibration (fixed wing)
      • See a full demo/walkthrough of the calibration feature here: https://www.youtube.com/watch?v=otveS5mgbu0
      • Trim following has always assumed a 1:1 relationship between trim position and elevator - many aircraft (especially 3rd party) are far from 1:1, causing the nose to wander when trimming with the stick held
      • A wizard-style assistant flies a short automated routine, measures your aircraft’s real trim response, and produces a calibrated trim-following curve you can apply and test live in the sim before saving
      • Run it at multiple airspeeds and the results blend into a single speed-aware curve; review, delete, export, and import stored calibrations from the dialog
      • Trimmed stick position modes: ‘Follows Trim’ (cable/trim-tab aircraft: the stick rides the trim like the real linkage) or ‘Stays Centered’ (airliners/FBW - the jet default); out-of-trim force behavior is identical either way
      • Glider support (steady-descent routine), suggested calibration speeds from each aircraft’s own envelope, and a main-window prompt when an uncalibrated aircraft loads
      • Factory calibrations included for several default aircraft (MSFS 2024: C172, C152, C208B, SR22T, Citation, Vision Jet, DG-1001E Neo | X-Plane 12: C172, SR22, RV-10)
      • NOTE: some aircraft are non-calibratable - trim that overpowers full elevator, extreme trim sensitivity, or automatic trim systems that cannot be disabled
    • NEW: ‘Dynamic’ stall buffet style - irregular, gusty shaking that surges and grows heavier as the stall deepens (‘Classic’, the original steady shake, remains the default)
      • Both styles now key buffet onset and strength to each aircraft’s own stall speed and AoA - slow aircraft buffet fully at their own stall, and X-Plane buffet builds as the stall horn fires instead of arriving well after it
    • NEW: Telemetry Overrides editor in the Utilities menu (SimConnect/Dataref Overrides)
      • Per-aircraft overrides that re-source a telemetry item from an addon’s custom variable (SimVar/LVar or dataref) or subscribe to additional telemetry items - useful for sophisticated addons whose systems don’t drive the standard variables (autopilot state, custom engine/flight models)
      • Optional scale/transform converts the replacement value into the units the effects expect; changes save and apply immediately, verifiable in the Monitor tab
      • See the ‘Telemetry Overrides’ section of the documentation for details

    MSFS

    • NEW: Control lock feature added for Fixed wing and Helicopter aircraft:
      • Saab 340, PC-6 Porter, Wilga, Beechcraft A36 Bonanza, Beechcraft B58 Baron, A2A Comanche PA-24, Cessna 414, Beechcraft Duke
      • Taog H500
    • NEW: Taog H500/OH6 special implementation with optimized spring and trim configuration
    • NEW: 3-axis turbulence physics model with pitch/roll/yaw decomposition (shared with X-Plane)
    • CowanSim S76: Updated default profile; added option to disable ROTOR TRIM RESET command
    • FlyInsideHeli: Engine vibrations now mapped to pedals and collective axes
    • HPG Pedals: Added force trim button option
    • HPG Collective: Sends axis position while vertical mode is active to avoid an axis snap when disengaging the autopilot
    • Fix: the ‘AP Pitch - Follow axis instead of trim’ setting had no effect (broken since mid-2025) - when enabled, autopilot following now correctly moves the stick with the elevator position instead of the trim
    • Fix: restored CowanSim and Taog H500 helicopter features that had been inadvertently dropped
    • Fix: heli trim following issue (MSFS/X-Plane)
    • Fix: intermittent stale/missing aircraft display when starting TelemFFB while the sim was already running (telemetry frame arriving during startup could be silently dropped)

    DCS

    • Export DLL updates
      • Added C-130 Hercules
      • Added AH-6 / MH-6 Little Bird
      • Added F100D
      • Fixed rudder control surface telemetry
    • DCS start/stop event handling: TelemFFB UI now responds earlier when the DCS export module loads or unloads
    • TelemFFB will now log a (non blocking) exception if DCS Realistic or SimHaptic are installed with the autostart feature enabled in export.lua (breaks DCS FFB)
    • Hardware force trim modes (joystick, pedals, collective) now honor the in-cockpit force trim switch for UH1/OH58

    IL2

    • NEW: IL-2 Korea support
      • KNOWN ISSUE: IL-2 Korea is not outputting any engine RPM info, therefore the RPM-based engine rumble effects are non-functional (see the new alternative engine shake effect below)
    • IL-2 Korea: default aircraft profiles included with starter Advanced Spring curves
    • IL-2 Korea: new spring override option leveraging the ‘ffbdevice’ telemetry stream (stream is configured automatically by auto-setup)
    • NEW: Alternative engine shake effect driven by raw engine shake frequency/amplitude data from the FFB telemetry stream
      • provides engine vibration feel on aircraft/titles where RPM telemetry is unavailable
    • NEW: forward raw IL-2 telemetry, motion, and FFB UDP streams to one or more external IP/port destinations, with each destination independently choosing which stream(s) to receive (System Settings > IL2)
    • Advanced Spring Override enhancements
      • Game-supplied spring center (‘ffb telemetry’) can now stack with a custom spring gain curve - the sim controls the center while your curve controls the force
      • New trim reset button binding
    • Fix: telemetry pause/flicker during multiplayer menus; removed unreliable window-focus-based pause detection
    • Fix: airborne deceleration effect
    • Fix: g-force effect activating incorrectly on aircraft that report weight-on-wheels while airborne (now treated as airborne when all gear are retracted)

    Effects

    • NEW: Helicopter Blade Slap effect (MSFS / X-Plane / DCS)
      • The signature ‘wop-wop’ of blade-vortex interaction: sharp kicks at blade-passage rate, felt where you hear it - shallow descents, decelerating approaches, flares, and loaded turns - on joystick, pedals, and collective
      • X-Plane drives it from the sim’s own computed blade-slap signal (including tail rotor slap); MSFS and DCS infer it from flight state, tunable via ‘Blade Slap Band Center’ and ‘G-Induced Slap Factor’
      • Two-bladed teetering rotors (Huey, R22) slap hardest; per-model tuning ships for the default helicopter profiles
    • New envelope and detent effect support in HapticEffect
      • Attack envelope on constant force effects — reduces the risk of jarring axis slam on initial activation
    • Propeller engine rumble: smoother at high RPM (all sims) - the detune ‘wobble’ that gives the rumble its chunky character at idle now fades as RPM rises, instead of persisting as a wah-wah undertone at cruise; the low-RPM feel is unchanged

    Big TelemFFB 2.0 Update

    Platform

    • Updated UI framework leveraging the latest PyQt6 libraries
    • Brand new look and feel
      • Settings are categorized for easier access
      • New, better management of multiple devices with easy to see icons compared to legacy clickable device labels
      • Easier to switch between various effect mode settings (like different spring or g-effect types)
        • relevant sub-options are displayed only if mode is active
      • Detachable Monitor tab
        • Now you can see the ‘Active Effects’ and edit settings at the same time
    • Support for Dark Mode theme
      • Light-mode, Dark-mode or system-controlled setting can be configured in System settings
        • Defaults to system controlled so will pick up your current windows theme setting
      • Can force light/dark mode with ‘–lightmode’ or ‘–darkmode’ runtime flags
    • All new Offline & Sim/Class default editor
      • Same interface as typical real-time configuration
      • Legacy offline interface has been retired
      • Easily move a model setting into a class/sim default by right-clicking on the delete button and selecting ‘move to’
    • New Profile Manager capability
      • Easily create additional settings profiles for any aircraft.
      • Profiles can be created as new or cloned from an existing one
      • Easily switch between profiles in the Profile Manager window or in real-time from the main App.
      • Profiles can be exported/imported individually or en masse with or without supporting class/sim default settings
      • Previously exported profiles can be imported. Options to include, exclude or rename profiles in the import file are available
      • ** On first load of new version, your existing configurations will be converted to a new profile based config. Legacy config will be retained for use with previous versions of TelemFFB.
        • All of your existing settings will be converted into ‘Auto User’ profiles for each aircraft
        • Please READ THE MANUAL

    All Sims

    • New ‘Advanced Spring Override’
      • New custom widget allows precise smoothed curve definition with multiple points
      • You can now define a custom spring curve over a given airspeed envelope
      • Separate defitions for X/Y axes
      • Supported on Pedals and Joystick
      • Curve configurations are exportable/importable for easier sharing between users.
    • New ‘Advanced G-Effect’
      • Leverages the same custom curve widget as the new advanced spring curve
      • Defines the effect force over a given G-loading range
      • Supports two effect modes
        • Constant Force: Similar to legacy G-effect
        • Spring Offset: Uses new firmware capabilities to drive the spring-center forward/back to create a strengthening effect on the spring when the stick is held still

    BMS (Beta)

    • Newly added support for Falcon BMS
      • Support is considered Beta at this time. Basic effects (engine rumble, afterburner, gunfire, etc) are tested. Many effects are untested.
      • Use it and report found issues/non-working effects please

    DCS

    • Support added for F4U-Corsair
    • New high-performance compiled telemetry exporter.
      • Performs same function as legacy lua script, but with a fraction of the overhead
      • Reduces likelyhood of potential negative interactions with (or from) other DCS export scripts
    • Dynamic ‘Autopilot Deadzone’ - Can dynamically apply a axis deadzone via the configurator API when AP is activated
      • Requires new DLL based telemetry export
      • Available on select aircraft currently: F-14, F-18, A-10, F-4

    MSFS

    • Steering Friction
      • Adds a small to moderate amount of friction effect while on the ground and below a speed threshold. Friction will increase as airspeed decreases
    • New Turbulence Effect
      • Monitors relative wind data and reacts to gusts, providing a small to moderate constant force effect based on the wind data in the x/y polar axes
    • New ‘FlyInsideHelicopter’ sub-type to support effects leveraging FFB specific data available from Fly Inside helicopters
      • Currently includes shake type effects for things like blade slap, ETL and VRS.
    • Fix case in MSFS24 where aircraft with ‘electric’ engine types were not properly being processed
    • Helicopters - Simvar based force trim toggle
      • Enable ‘Force Trim Switch’ while Force Trim spring mode is selected
      • Toggle “L:TelemFFBHeliFT” with Spad.nExt, AoA or other external tool
      • If heli has force trim switch in cockpit, replace the L:Var config with the applicable L:Var to control using in-cockpit switch

    IL2

    • Enhanced telemetry based gunfire effect
      • Gun data (mass, velocity) is read from telementry and used to create a dynamic intensity/fire rate effect
      • Smaller/faster rounds will produce a higher frequency effect while larger/slower rounds will pack more of a punch at a lower rate

    DCS/IL2/MSFS/XPLANE

    • New G-Force effect for fixed wing aircraft
      • The original effect worked OK, but the “curvature” of the applied force would often lead to oscillations or a jerky feeling
      • The new effect uses a linear calculation based on the min/max G settings to determine the primary force factor
      • The physical stick deflection is then used as a factor to determine the final applied force. For any given g-loading, “the harder you are pulling, the more force you will feel”
      • The range of stick deflection that results in %100 applied force is adjustable
      • Allows for negative G effect also.
      • For DCS/IL2, If both the new and old effects are enabled at the same time, the new effect takes precedence. The legacy effect was not previously available for MSFS/XPLANE.

    Release - June 22, 2024

    QoL Improvements

    • New system tray implementation (see manual)
      • TelemFFB can now be sent to system tray on startup and/or close button. Window can be recalled by double-clicking the tray icon or from the icon right-click context menu
      • System tray icon color indicates simulator run/pause/error state like the existing status icons
      • Configuration errors (such as enabling MSFS force trim and having no binding configured) now present the error message in the UI, and generate a system tray notification for easier recognition of the issue.
    • Real-time settings usability improvements
      • Values update in near real-time when manipulating sliders
      • Manipulating sliders no longer causes a form re-load
      • -/+ buttons added to left/right of slider for single step adjustments
        • Shift+Scroll wheel or left/right up/down arrow keys while hovering mouse of the slider is also supported
    • Minor UI overhaul
      • Look and feel updates with on/off sliders in lieu of checkboxes and improved icons.

    General

    • Configurator effect slider overrides (see manual)
      • Now you can directly modify, in real-time, the slider gain setting for any of the effect types without creating and pushing a separate vpconf file
      • Can be overridden on a per Sim/Aircraft Class/Specific Aircraft basis
    • Minor enhancement to gear and canopy movement effects. You will feel a bump/clunk when the gear fully extend/retract or when the canopy (when applicable) closes

    MSFS

    • Improved/Simplified settings for adjusting dynamic spring forces (see manual)
      • Prior “Gain” setting is removed and the “Max Force” setting is now affixed to the aircraft “Vne” speed (learned via telemetry) while maintaining true dynamic forces based on aerodynamic conditions.
      • “Expo” adjustment to adjust the rate at which the force falls off at low speeds.
      • RTFM for the best experience using these new settings.

    DCS

    • Added tail-hook movement effect (supported on a/c with tailhooks)
    • Added wing-fold effect (F/A-18, F-14)
    • Added fuel-boom effect (supported on all a/c with fuel boom/door)
    • Added Co-Pilot/RIO Spring Override feature
      • Can temporarily override/disable spring force when user has moved away from pilots seat. Optionally can bind a button that must also be held down.
      • Note that seat data is not available at this time for some aircraft (like the F-4E).

    May 19, 2024

    General/System

    • Major code refactoring and re-organization of code

      • NOTE: *** Users running from python natively will need to re-run the requirements.txt pip install or manually install the “stransi” python library ***
      • NOTE: *** The format of the system settings in the registry has changed, thus you will need to re-configure your TelemFFB system settings. ***
      • Distribution structure has been changed. You will again notice some subfolders that contain the compiled python libraries and other supporting files. This was done to aid in reducing false positive malware detection.

    • Dynamic SimConnect Subscriptions
      • Some 3rd party aircraft use alternate “L:Vars” for certain pieces of data that various effects use. This renders the applicable effects either inoperable or inaccurate.

    DCS

    • New, more accurate Airspeed Telemetry
      • It was recently discovered that both the ‘TAS’ and ‘IAS’ data that comes directly from the sim is inaccurate in several ways. The ‘TAS’ data seems to be more in line with ground speed. Th “IAS” data, while more accurate, seems to include a fixed value, regardless of heading, that is somewhere around 2x the current wind speed.
      • Given the above inaccuracies, with most effects leveraging the ‘TAS’ data, you may have noticed odd behavior of effects like ETL.
      • In this version, we are calculating the “true” TAS by using the aircraft velocity vectors and the wind vectors to determine the aircraft’s actual speed through the air mass. This has given us a much more accurate data set than was previously available from the sim.
    • Helicopter Trim Release Damper
      • This is not a replacement of the in-game trim release functionality. It is a simple spring based dampening effect, identical to the one for MSFS.
      • To configure, simply enable the effect and bind the same button that you have configured for TR in the sim. While the button is depressed, TelemFFB will add the dampening effect and will remove it when the button is released. The actual trimming and centering offset is still completely handled by DCS.

    New pedal features for DCS: - Rudder trim for fixed wing aircraft - Auto spring mode switching for Heli/Jet/Prop aircraft types (or per aircraft)

    Default Behavior is as follows: - ‘JetAircraft’ - Pedal trimming enabled - Spring mode = Static - Static spring based on configurable spring and dampening gain

    • ‘PropellerAircraft’

      • Pedal trimming enabled
      • Spring mode = Dynamic
      • Dynamic force based on configurable spring and dampening gain. Force will be applied linearly with 0 at rest, %25 at the published Vs speed and %100 at the published Vne speed.
      • In an effort to keep as much complexity out of the config as possible, these Vs and Vne values are currently hard coded for the DCS warbirds, but instructions exist in the manual for overriding or for setting up a different aircraft to use dynamic pedal forces.

    • ‘Helicopter’

      • Pedal trimming not supported (sorry, I tried multiple ways but DCS is too broken in this regard for helicopters that even have pedal trimming)
      • Spring mode = Disabled
        • Configurable dampening gain is available
