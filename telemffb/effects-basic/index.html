    1. Basic Settings¶

    The settings that define how your controls fundamentally feel (the spring model, force trim, axis control, and per-aircraft basics) in the order they appear under the Basic Settings section of the Settings tab. The badge lines and sub-setting tables are generated from the application’s settings catalog, so they always match the app.

    1.1 Class¶

    DCS IL2 BMS MSFS XP · All devices

    The aircraft class: PropellerAircraft, TurbopropAircraft, JetAircraft, GliderAircraft, Helicopter, or a special class such as HPGHelicopter (choices depend on the simulator). The class decides which class defaults apply and which spring modes and effects are offered; see How Settings Work.

    1.2 Spring Mode¶

    DCS IL2 BMS MSFS XP · All devices

    The master selector for how the centering spring behaves. The available modes depend on the simulator, aircraft class, and device; an MSFS fixed-wing joystick offers different modes than DCS helicopter pedals or a collective. Each mode reveals its own sub-settings, listed below by mode.

    • For MSFS/X-Plane, the spring modes are the core of the FFB implementation; see Axis Control & Spring Modes.
    • For DCS, the default is the game-managed spring; the override modes are described in the DCS guide, including the pedal modes.
    • For a collective, the modes are No Spring and Hardware Force Trim; see Collective Spring Mode.
    • Advanced Dynamic is configured through its own curve editor; see Advanced Spring & G-Force Curves.
    • Force Trim (helicopters and gliders) holds the stick where you release the trim button; see Helicopter Force Trim. Many gliders have a lever-actuated trim system that works the same way, which is why the aileron/elevator force-trim options exist for gliders too.

    1.3 Disable Collective Spring¶

    DCS BMS MSFS XP · Collective

    When flying a fixed-wing aircraft with a collective connected, TelemFFB normally zeroes the collective’s spring gain (a fixed-wing throttle has no centering spring). This option disables that behavior.

    1.4 Trim Wheel Buttons¶

    MSFS XP · Trimwheel

    MSFS XP · Trimwheel

    MSFS XP · Trimwheel

    For a VPforce trim wheel device: use button inputs from the master device (or the wheel itself), and bind the nose-down / nose-up trim buttons.

    1.5 Trim Workaround¶

    DCS · Joystick

    Some DCS modules (AV-8B, MiG-19) do not implement native FFB trim following. This workaround mimics it by moving the physical joystick with the trim.

    1.6 Pedal Force Trim¶

    MSFS XP ·

    Enables a static spring on the pedals with a force-trim release button: hold the button, position the pedals, release to lock the new center.

    1.7 IL2 Shake Master¶

    IL2 · All devices

    IL-2 implements its own basic FFB shake effects in-game. The Shake Master group replaces them with TelemFFB’s more configurable versions: buffeting, runway rumble, and weapons effects, each individually adjustable. When using these, set the in-game “Shaking” intensity to 0; see the IL-2 guide.

    Note

    IL-2 provides a single combined buffeting channel (stall, gear, and so on share one intensity), a limitation of the IL-2 telemetry, not of TelemFFB. The Dynamic Gunfire Mode reads shell mass and velocity from telemetry, so lighter, faster-firing guns feel quicker and sharper than heavy cannon.

    1.8 Axis Control¶

    MSFS XP · All devices

    MSFS/X-Plane only: TelemFFB becomes the source of the axis positions the simulator receives, the foundation for the spring modes, trim following, and autopilot following. The family includes the axis scales, hands-on detection, custom axis variables, and the entire Trim/AP Following tree.

    Important

    When Axis Control is enabled in MSFS, you must unbind the affected axes in MSFS (or SPAD.neXt). See Axis Control & Spring Modes.

            ↳ Trim Curve Calibration MSFS, XP · Joystick Auto-calibrated elevator trim response curve. Captured by the Elevator Trim Calibration tool; used when ‘Use Calibrated Trim Curve’ is enabled.
            ↳ Calibrated Trim Stick Travel MSFS, XP · Joystick How far the stick sits from center for a given amount of out-of-trim - which sets how much force you feel holding against it. 100% is the aircraft’s measured response, exactly as the calibration recorded it. In ‘Stays Centered’ this affects out-of-trim force only; trimmed flight always rests the stick at center. In ‘Follows Trim’ it also scales how far the resting position rides with airspeed. Raise it to exaggerate that trim-position cue, or lower it if the stick sits so far aft in slow flight that you run out of usable travel. It does not change the calibration or the trim curve - trimming with the stick held never moves the nose, at any setting. Away from 100% a released stick delivers a small residual input, so a hands-off aircraft will not follow its trim quite exactly; in ‘Follows Trim’ this also shows up as slow drift when trimmed at the extremes of your calibrated speed range.
            ↳ Trimmed Stick Position MSFS, XP · Joystick Where the stick rests when the aircraft is trimmed, with calibrated curves at multiple speeds. ‘Follows Trim’: the rest position rides the measured trim state - aft when trimmed for slow flight, forward when fast - like cable/trim-tab aircraft where the yoke is linked to the control surface. ‘Stays Centered’: trimmed flight always rests the stick at center - like moving-stabilizer, FBW or spring-cartridge aircraft where trim re-rigs the feel datum. Force behavior is identical in both modes (trimmed = zero force, out-of-trim = force); only the resting geometry differs.

    1.9 Collective AP Spring Gain / Dampening¶

    MSFS XP · Collective

    HPG helicopters: the spring strength applied to the collective while the AFCS/autopilot commands it. See HPG Airbus Helicopters.

    1.10 HPG Pedal Spring Gain¶

    MSFS · Pedals

    HPG helicopters: the pedal spring gain used by the AFCS integration, as a percent of the Configurator spring value.

    1.11 Co-Pilot/RIO Spring Override¶

    DCS · Joystick

    DCS multi-crew: temporarily overrides the joystick spring gain when you occupy a seat other than the pilot’s, so the stick is not fighting you while you work the back seat. Optionally active only while a configured button is held.

    Sub-setting Sims What it does
    Pilot Seat ID — Seat ID when sitting in Pilot’s seat. Effect will beome active any time the Seat ID does not match this ID value See the Telemetry monitor page to get the proper value when sitting in the pilots seat
    Spring Gain — Spring gain while effect is active
    Only on Button Press — Only activate override if button is held (must configure button in resulting setting once this setting is enabled)
        ↳ Override Button — Click to configure the override button

    1.12 Autopilot Deadzone¶

    DCS · Joystick

    DCS: applies a device deadzone while the autopilot is engaged, preventing small FFB stick movements from feeding back into the AP control loop and causing false disconnects or oscillation. Supported on a limited set of modules; see Autopilot Oscillation with FFB.

    Sub-setting Sims What it does
    Autopilot Deadzone — Enable a configurator axis deadzone when AutoPilot is active to reduce false disconnects Supported on limited modules
