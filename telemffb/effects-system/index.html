    1. System Settings (Per-Aircraft)¶

    Non-effect settings that can be configured per aircraft, in the order they appear under the System section of the Settings tab. The badge lines and sub-setting tables are generated from the application’s settings catalog, so they always match the app.

    1.1 TelemFFB Profile¶

    DCS IL2 BMS MSFS XP · All devices

    Selects a named TelemFFB settings profile to activate for this aircraft; see Aircraft Profiles.

    1.2 Configurator File¶

    DCS IL2 BMS MSFS XP · All devices

    Pushes a specific .vpconf file (created with VPforce Configurator) to the device when this aircraft loads. The pushed profile stays active until another sim, class, or model setting pushes a different one. See VPconf Profiles & Gain Overrides.

    1.3 Override Configurator Sliders¶

    DCS IL2 BMS MSFS XP · All devices

    Directly modifies the per-effect-type gain sliders on the device when this aircraft loads, a lighter-weight alternative to pushing a whole .vpconf file. See VPconf Profiles & Gain Overrides.

    Sub-setting Sims What it does
    Override Configurator Sliders — Directly modify the per-effect type gain values on the VPforce device. Please read the manual to understand how it works and how it interacts with the “Configurator File” feature (these gains will override any pushed in a configurator profile)

    1.4 Command Runner¶

    DCS IL2 BMS MSFS XP · All devices

    Executes a shell command when the aircraft loads: start a companion utility, run a batch script, or any other action executable from a command line.

    Warning

    The command runs exactly as entered, with no validation. Treat it with the same care as anything you would type into a terminal.

    Sub-setting Sims What it does
    Command Runner String — Enter a command to be executed when an aircraft loads. There is no path or validation checking. Command will be executed as is. Enter the command with the full path exactly as if running from a command prompt

    1.5 Center on Pause/Slew¶

    MSFS XP · All devices

    Forces spring centering while the simulator is paused or in slew mode. When disabled, you will need to bring the axis close to center to re-establish axis control after unpausing.

    1.6 Keep Forces on Pause/Slew¶

    DCS IL2 BMS MSFS XP · All devices

    Keeps the damper/inertia/friction forces active while the simulator is paused, instead of letting the stick go slack.
